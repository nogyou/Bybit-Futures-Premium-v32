# BYBIT FUTURES PREMIUM v3.2.7 — 가격축·매매구간 차트 개선 (Beta)

기존 v3.2.6의 전체시장/단타·단기·장기 양방향 분석/AI 포지션 관리/뉴스/레버리지 기능을 유지하면서 **차트 표시만 수정**한 개발본입니다.

## 차트 개선
- 현재가: 캔들 전체를 가로지르는 **얇은 노란 실선**, 오른쪽 가격축에 **작은 노란 사각형 가격표** (차트 내부의 큰 가격표 제거)
- 가격 탐색: PC 포인터 위치에 **가로 실선만**, 태블릿은 **차트를 0.33초 길게 누른 후 위아래 이동**하면 가로 실선·오른쪽 회색 가격표 표시; 기존 가로 드래그 과거 탐색/두 손가락 확대축소는 유지
- 현재가 가격표와 탐색 가격표가 가까우면 탐색 가격표의 위치만 조정해 중첩을 줄임. 가격선은 실제 가격 Y 위치에 유지.
- 차트 AI LONG/SHORT 표시: 복잡한 TP1/TP2/SL 라벨 대신 **LONG 진입 구간·LONG 익절 구간 / SHORT 진입 구간·SHORT 익절 구간**만 표시. 각 익절 구간은 기존 분석 엔진의 *독립적인 구조적 TP1~TP2* 범위를 시각화하며 TP1 또는 TP2가 확인되지 않으면 구간을 생성하지 않음.
- 진입 구간 밴드는 기존 엔진의 단일 진입 후보 가격 주변의 **시각적 허용 폭**으로, 별도로 검증된 매수 체결 가능 가격 구간은 아님.
- 위험관리 정보인 SL/정확한 TP1·TP2/근거/ROI/청산 위험은 기존 오른쪽 AI 종합 판단에서 계속 확인 가능.
- 가격축 오른쪽 공간, 차트 높이, 기본 82개 캔들 표시와 줌 및 다른 구성은 유지.

## 설치·빌드
기존 저장소 `Bybit-Futures-Premium-v32`의 소스 파일에 덮어쓴 후 GitHub Actions로 APK 빌드. 앱 ID: `com.bybit.tradeterminal.v327` (v3.2.6과 병행 설치 가능).

## 중요
규칙 기반 시장 분석 베타로, 차트 구간 표시가 실거래 수익을 보장하지 않습니다. 실제 기기에서의 WebSocket/차트 터치 제스처/APK 설치는 아직 검증하지 않았습니다. 뉴스는 표시 전용이고 매매 신호 점수에는 자동 반영되지 않습니다.
